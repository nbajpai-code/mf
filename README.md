## 🎯 What is Mental Food?

Just as we're mindful about what we eat, we should be intentional about what we consume intellectually. **Mental Food** is a curated collection of high-quality, thought-provoking technical content that challenges your thinking, expands your knowledge, and inspires innovation.

This repository focuses on:
- 🎥 **Technical talks** from industry leaders
- 📄 **Research papers** that shaped AI/ML
- 📚 **Books** for deep understanding
- 🎓 **Online courses** from top universities
- 🎙️ **Podcasts** for continuous learning
- ✉️ **Newsletters** to stay current

## 🔄 Recommended Consumption Framework

### Daily (15-30 min)
- 📄 Read one paper abstract or blog post
- 🎙️ Listen to a podcast segment during commute

### Weekly (2-3 hours)
- 🎥 Watch 2-3 technical talks
- 📝 Write summaries of key learnings
- 💡 Implement one new concept

### Monthly
- 🎓 Complete one course module
- 📚 Read one book chapter
- 🔬 Deep dive into one research area
