# Open Source AI Projects & Ecosystem (2025)

This repository contains a curated list of the most impactful open-source Artificial Intelligence projects, frameworks, and agents.

## 🧠 Large Language Models (LLMs)

### **Llama 3 (Meta)**
The state-of-the-art open weights model setting the standard for open-source AI.
*   **Focus**: General purpose, instruction following, coding.
*   **Repo**: [meta-llama/llama3](https://github.com/meta-llama/llama3)

### **Mistral / Mixtral (Mistral AI)**
Highly efficient Sparse Mixture-of-Experts (MoE) models (e.g., Mixtral 8x7B, 8x22B) known for outperforming larger dense models.
*   **Focus**: Efficiency, multilingual support, long context.
*   **Repo**: [mistralai/mistral-src](https://github.com/mistralai/mistral-src)

### **DeepSeek V3 (DeepSeek)**
A powerful open-source MoE model with strong reasoning and coding capabilities, often compared to top-tier proprietary models.
*   **Focus**: Reasoning, Math, Code.
*   **Repo**: [deepseek-ai/DeepSeek-V3](https://github.com/deepseek-ai/DeepSeek-V3)

### **Qwen 2.5 (Alibaba)**
A comprehensive suite of models ranging from 0.5B to 72B parameters, known for strong performance in coding and mathematics.
*   **Focus**: Versatility, Code, Math, Multilingual.
*   **Repo**: [QwenLM/Qwen2.5](https://github.com/QwenLM/Qwen2.5)

### **Gemma 2 (Google DeepMind)**
A family of lightweight, state-of-the-art open models built from the same research and technology used to create the Gemini models.
*   **Focus**: Lightweight, Responsible AI.
*   **Repo**: [google/gemma_pytorch](https://github.com/google/gemma_pytorch)

### **Phi-3 / Phi-4 (Microsoft)**
Highly capable Small Language Models (SLMs) that punch above their weight class, suitable for mobile and edge devices.
*   **Focus**: Edge computing, reasoning on small hardware.

## 🤖 AI Agents & Frameworks

### **LangChain**
The standard framework for building applications powered by LLMs, facilitating chaining, RAG, and memory.
*   **Repo**: [langchain-ai/langchain](https://github.com/langchain-ai/langchain)

### **AutoGen (Microsoft)**
A framework that enables the development of LLM applications using multiple agents that can converse with each other to solve tasks.
*   **Focus**: Multi-agent collaboration.
*   **Repo**: [microsoft/autogen](https://github.com/microsoft/autogen)

### **CrewAI**
Framework for orchestrating role-playing, autonomous AI agents. By fostering collaborative intelligence, CrewAI empowers agents to work together seamlessly.
*   **Focus**: Role-based agent orchestration.
*   **Repo**: [joaomdmoura/crewAI](https://github.com/joaomdmoura/crewAI)

### **LlamaIndex**
A data framework for LLMs to ingest, structure, and access private data. Essential for RAG (Retrieval-Augmented Generation).
*   **Focus**: Data ingestion, RAG.
*   **Repo**: [run-llama/llama_index](https://github.com/run-llama/llama_index)

## 👁️ Computer Vision & Multimodal

### **Stable Diffusion 3 / XL (Stability AI)**
State-of-the-art text-to-image generation models.
*   **Repo**: [Stability-AI/generative-models](https://github.com/Stability-AI/generative-models)

### **YOLOv10 / YOLO11 (Ultralytics)**
The standard for real-time object detection and image segmentation.
*   **Focus**: Real-time speed and accuracy.
*   **Repo**: [ultralytics/ultralytics](https://github.com/ultralytics/ultralytics)

### **OpenCV**
The foundational library for real-time computer vision.
*   **Repo**: [opencv/opencv](https://github.com/opencv/opencv)

### **Whisper (OpenAI)**
Robust speech recognition model via large-scale weak supervision.
*   **Focus**: ASR (Automatic Speech Recognition), Translation.
*   **Repo**: [openai/whisper](https://github.com/openai/whisper)

## 🛠️ Core Frameworks & Infrastructure

### **PyTorch**
The dominant deep learning framework for research and production.
*   **Repo**: [pytorch/pytorch](https://github.com/pytorch/pytorch)

### **TensorFlow / Keras**
End-to-end open source platform for machine learning.
*   **Repo**: [tensorflow/tensorflow](https://github.com/tensorflow/tensorflow)

### **Hugging Face Transformers**
The library for state-of-the-art pre-trained models.
*   **Repo**: [huggingface/transformers](https://github.com/huggingface/transformers)

### **Ollama**
Get up and running with Llama 3, Mistral, Gemma, and other large language models locally.
*   **Focus**: Local LLM inference.
*   **Repo**: [ollama/ollama](https://github.com/ollama/ollama)

### **vLLM**
A high-throughput and memory-efficient inference and serving engine for LLMs.
*   **Focus**: Production inference.
*   **Repo**: [vllm-project/vllm](https://github.com/vllm-project/vllm)
